# Third party

| what | who | shipped here? |
|---|---|---|
| O2Jam game, songs, charts, artwork | O2Media / Nowcom and the original artists & noters | **no** - not a single song file is in this repo |
| CXO2 client | the CXO2 project | **no source** - only our own patch diffs in `patches/` (their repo has no licence) |
| Song chart metadata (titles, levels, BPM, note counts) | read from the user's own `.ojn` files | yes, as a catalogue (`catalog.json`, `songs.csv`, `CATALOG.md`) |
| Download mirrors | Internet Archive item `o2jam_musicpack` | links only |

The catalogue exists so a legally owned copy of the game can show and download its songs. If you
are a rights holder and want an entry removed, open an issue and it is gone.
